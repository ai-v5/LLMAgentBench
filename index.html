怎么看：得分就是通过率，首轮与含自动修复分别计算；失败、未评分、错误和超时都计入分母。公开题使用合成任务；全部题目包含公开与未公开任务，页面只展示总体得分。

输出速度：公开题的候选输出 token 数 ÷ 候选调用耗时，包含客户端启动、网络、等待与修复；输出 token 可能包含推理 token，各执行器口径和分词器可能不同，这不是服务端纯解码速度。

结果边界：Codex 与 DSH 的输出约束不同；当前是有限样本的结构化响应与补丁测试，不构成通用模型排名。部分题目曾用于模型试跑与调整，并非独立留出集。历史 Codex 运行未隔离全局指令，工作区外文件读取隔离也未核实。模型是请求值，服务端身份未独立观测。部分题目使用 Sol 裁判，Sol 候选存在同模型评分偏差的可能。

Terra 20261110：公开题得分和经授权的总体得分分别展示；私有题目内容与逐题结果不公开。max 复用了题目和验收一致的历史样本并补测其余题目。历史单轮超时为 240 秒，新运行是 600 秒；执行器、客户端和 Windows 沙盒条件也不同，不应将三档视为完全相同条件的对照。只读沙盒不代表已验证工作区外文件的读取隔离。

Luna 20261110：max 复用了题目和验收一致的历史公开样本；历史单轮超时为 240 秒，新运行是 600 秒，执行器、客户端和沙盒条件也不同。各档结果的条件及边界见结果说明。
